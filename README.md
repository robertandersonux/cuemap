# CueMap

CueMap helps you build habits by changing your space instead of relying on willpower. Pick a room and a habit, and it gives you one physical change you can make in under five minutes, plus why it works.

## Features

- 40 suggestions covering 5 rooms and 8 habits, each one a single change you can make right now
- A map of your home that groups your saved changes by room
- Add a photo of each change and mark it as made
- Saves on your device, with no account needed
- Runs in the browser and as an Android app

## Built with

React · TypeScript · Vite · Capacitor (Android)

## Getting started

Requires Node 22 or newer (run `node -v` to check).

    git clone https://github.com/robertandersonux/cuemap.git
    cd cuemap
    npm install
    npm run dev

Then open http://localhost:5173 (or the port shown in your terminal).

To build and run the Android app, see [ANDROID.md](./ANDROID.md).
